# Horizon Purr Data Theme

https://github.com/user-attachments/assets/14ce3b11-ee4e-4747-86c4-d2df9c4cad9e

This is a theme for [Purr Data](https://www.purrdata.net) based on the [Horizon VS Code Theme](https://github.com/jolaleye/horizon-theme-vscode).

Install it by copying `horizon.css` into the `css` folder within your Purr Data directory - on Arch Linux this is `/opt/purr-data/lib/pd-l2ork/bin/css`.
You can then select the theme from Purr Data's preferences in the GUI tab.
